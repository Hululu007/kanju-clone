# 追剧AI iOS 交互规格 v2（照抄腾讯视频，草稿 2026-11-19）
只抄布局和交互；不搬腾讯 logo、图标、美术素材。去掉：开通会员、广告、弹幕、二创/讨论、VIP/预告角标。

## 1. 详情播放页（竖屏）
- 播放器顶部：返回 ‹ ｜ 右侧 投屏、分享、更多 ···
- 播放器底部：播放/暂停、当前时间、进度条、总时长、全屏按钮
- 播放器下方：剧名（大字）+ 右侧两个图标：追剧（加入片单）、下载 ⬇
- 信息行：类型 · 评分 · 标签 · 简介 ›（点开简介面板）
- 选集：标题「选集 全N集 ›」；如有多版本/季，下面一排横滑标签；再下面一排横滑方形集数块（当前集高亮青色）。点「全N集 ›」展开全部集数网格
- 再下面：相关推荐海报横排（海报 + 全N集）

## 2. 下载页（点剧名旁 ⬇ 打开，整页推入）
- 标题：点击集数即可下载；左上返回
- 第一行：下载画质  720P ›（可选画质）
- 集数网格：每行 6 个方块，间距均匀；点一下 = 立即加入下载，方块变青色并显示下载中/已下载状态
- 底部：只有一个「查看下载列表」按钮 + 剩余空间「剩余 xxG 可用」
- 不做「下载全部」（Ken 明确不要）

## 3. 我的下载
- 标题「我的下载」，右上「编辑」
- 顶部「正在下载」行：缩略图、剧名 + 第几集、进度条、速度；数字角标显示正在下载几集
- 已下载按剧分组：海报、剧名、已下载几集、占用大小；点进去看各集
- 每行左滑删除（同时删文件）
- 底部：已使用 xxM，剩余 xxG 可用

## 4. 全屏播放（横屏）
- 顶部左：返回 ‹、剧名 + 第几集、画面模式下拉「默认 ▾」（默认/拉伸/平铺，点了立刻生效，用 AVPlayerLayer.videoGravity）
- 顶部右：投屏、分享、更多 ···
- 左侧中部：锁屏 🔒；右侧中部：截图 📷
- 底部：当前时间/总时长、进度条；下一排 播放/暂停、下一集 ⏭；右侧 字幕、倍速、画质（720P）、选集
- 控制栏和画面模式下拉在点屏幕/暂停时出现，播放几秒后自动隐藏

## 5. 播放设置面板（全屏点 ··· 从右侧滑出）
- 第一排图标：下载、撑满全屏、画中画、音频播放
- 列表：定时关闭 ›；循环播放（单集/列表/关闭）；跳过片头片尾（开关）；分集标题（开关）
- 右上 ✕ 关闭

## 规则
- 小 UI 改动不写 XCUITest、不跑模拟器截图门禁，编译通过直接出 IPA
- 拿不准的交互照腾讯视频真机行为，不自创
