## 一、上次真机为什么「点下载没反应」

三个问题叠在一起，少修一个都看不到东西：

1. **网页发来的下载请求被原生直接扔了。** 网站只发「下载这个地址、这个名字」，没有登录标记、也没有任务编号。
   原生那边却要求「必须是已登录 + 必须带编号」，两条都不满足就悄悄返回了 —— 界面上当然什么都不发生。
2. **网页脚本自己也拦了一道登录。** 它去看旧站的登录钥匙（`kj-auth-token`），新站根本不写这个钥匙，
   于是请求连原生都到不了，直接被一句「登录后才能下载」挡回去。
3. **下载页刷新时调用的是已经删掉的函数。** 上一版删界面时把 `syncDownloadRow()` 一起删了，
   但进度推送的路径还在调它，一运行就报错；结果格子和「我的下载」永远停在第一次画出来的样子。

另外「两套播放器叠在一起、转屏乱」是第四件事：注入层自己仿了一套播放器控件，
还把网站自己的工具条藏了；全屏时它让原生锁竖屏、改页面尺寸，网站自己的全屏又走另一条路，两边打架。

## 二、这次改了什么

- **播放器只留网站那一套。** 删掉注入层自建的顶部条、全屏浮层、画面档位、倍速 / 外放 / 投屏菜单、复制链接，
  也删掉所有伪装全屏的样式。网站自己的工具条、顶栏右侧按钮、选集旁的投屏入口都恢复显示，不再被藏。
- **全屏和转屏交回网站 + 系统。** App 里删掉「让原生锁竖屏 / 改约束 / 强制转屏」这一整条路，
  现在是「网页播放器自己全屏 + 手机怎么转画面就怎么转」，App 在任何模式下都不锁方向。
- **下载不再被登录态或编号挡住。** 缺编号就按「哪部剧 + 哪一集」补一个固定的编号，同一集重复点下载还是同一条记录，
  续传、暂停、继续都接得上；单集请求也会带上剧号和集号，下载页格子与「我的下载」才对得上。
- **进度会动起来。** 下载中、下载完成、从后台回到 App 这三条路都走同一个刷新入口，
  下载页格子显示「下载中 N%」加进度条，「我的下载」显示总进度条和百分比。
- **下完能离线播。** 点已下载的一集，直接用手机自带播放器播本地文件（网页播放器播不了本地文件）。

## 四、真机上要一条条确认的事

1. 打开任意一集的详情/播放页，点网站自己的下载入口 → 下载页能打开，格子开始走进度。
2. 点某一格只下这一集，格子里出现「下载中 N%」和进度条。
3. 进「我的下载」：能看到正在下载的进度条 + 百分比 + 已下字节。
4. 下完之后点那一集 → 能离线播放（可以开飞行模式验证）。
5. 暂停 / 继续 / 取消整部剧，状态和文件都对得上。
6. 点网站播放器自己的全屏 → 横过来 → 竖回去 → 退出全屏：画面跟着转，工具栏和头栏不打架，能返回上一页。
7. 顶栏右侧的搜索 / 历史 / 菜单，以及选集旁的投屏入口，都还在、都能点。
8. 一次下多集（批量），确认并发和排队正常。
