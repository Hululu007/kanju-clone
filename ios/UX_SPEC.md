# 追剧AI iOS 交互规格（Ken 2026-11-19 03:30 定，所有 worker 必须照此做）

参考对象：腾讯视频 / 爱奇艺 / 优酷 iOS App 的播放页与离线缓存页交互。不要自创交互，拿不准就照它们做。
画面填充参考 Apple 原生：AVPlayerLayer.videoGravity（.resizeAspect=默认 / .resize=拉伸 / .resizeAspectFill=平铺），开源参考 jellyfin/Swiftfin 的播放器。

## 1. 画面填充（bug：拉伸、平铺点了画面无变化）
- 只在**全屏播放**时出现；竖屏/小窗、设置面板里全部移除。
- 全屏下**暂停**时，屏幕顶部控制栏显示 [默认][拉伸][平铺] 三个选项，当前项高亮；点了立刻生效（必须真的改 videoGravity / 等效实现）。
- 恢复播放后这排选项随控制栏一起隐藏。
- 记住上次选择。

## 2. 下载（照腾讯视频的"缓存"）
- 入口：播放页视频下方「选集」旁的「下载」按钮（已做，保留）。
- 点开后在按钮下方展开集数网格（每集一个格子，一行 5–6 个，不挤在一起，间距正常），格子上标状态：可下载 / 下载中(进度) / 已下载✓。
- **点一个格子 = 立刻加入下载队列**，格子马上变“下载中”，有轻提示“已加入下载”。一次点一集，可连续点多集。
- **不要“全选/一键全集下载”**，也不要“下载已选”二次确认按钮。
- 设置面板里的下载入口/多集列表全部删除。

## 3. 已下载列表（离线缓存页）
- 每个视频行支持**左滑删除**（iOS 标准 swipeActions，红色“删除”），删除同时删本地文件。
- 不做一键全部删除、不做多选删除。
