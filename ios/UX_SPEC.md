# 追剧AI iOS 交互规格（唯一规范来源，2026-11-19 更新至 v2 / 0.1.17）

本文件 = **唯一依据**。0.1.16 的小规格（画面填充三档、点一格即下载、左滑删除）已并入本文，
另加腾讯视频 iOS 的五屏布局与交互。规格里没写的，照腾讯视频真机行为做，不自创控件。

**边界（用户 2026-11-19 明确）**
- 只借鉴**布局与交互**。**严禁**使用腾讯视频的 logo、图标、美术素材；图标一律用本仓自绘/文字。
- 移除：开通会员、广告、弹幕、二创/讨论、VIP 与预告角标。
- 下载：**点单集即下载**，不做「下载全部」。
- 已下载：**只左滑删除**，不做批量。
- 本 App 是 WKWebView + `<video>`（**没有自己的 AVPlayerLayer**）。所以「`videoGravity`」的实现
  必须是**对当下可见的那个 `<video>` 计算并写入真实像素几何**，三档在屏幕上必须看得出差别
  （见 §4 与 REG-015）。
- 小 UI 改动不写 XCUITest、不跑模拟器截图门禁，编译通过即可出包；bug 修复仍走
  HARK-REGRESSION（先红后绿 + 写入 `ios/REGRESSIONS.md`）。

## 1. 详情播放页（竖屏）

- **播放器顶部**：`返回 ‹` ｜ 右侧 `投屏`、`分享`、`更多 ···`。
- **播放器底部**：播放/暂停、当前时间、进度条、总时长、全屏按钮。
- **播放器下方**：剧名（大字）+ 右侧两个图标：`追剧`（加入片单）、`下载 ⬇`。
- **信息行**：`类型 · 评分 · 标签 · 简介 ›`（点简介打开简介面板）。
- **选集**：标题 `选集 全N集 ›`；有多版本/季时下面一排横滑标签；
  再下面一排横滑方形集数块（当前集高亮青色）。点 `全N集 ›` 展开全部集数网格。
- **相关推荐**：海报横排（海报 + `全N集`）。

## 2. 下载页（点剧名旁 ⬇ 打开，整页推入）

- 标题：`点击集数即可下载`；左上返回。
- 第一行：`下载画质  720P ›`（可选画质）。
- 集数网格：每行 **6 个**方块，间距均匀；点一下 = **立即加入下载**，方块变青色并显示
  下载中 / 已下载状态。
- 底部：只有一个 `查看下载列表` 按钮 + 剩余空间 `剩余 xxG 可用`。
- **不做下载全部**。

## 3. 我的下载

- 标题 `我的下载`，右上 `编辑`。
- 顶部 `正在下载` 行：缩略图、剧名 + 第几集、进度条、速度；数字角标显示正在下载几集。
- 已下载按剧分组：海报、剧名、`已下载 N 集`、占用大小；点进去看各集。
- 每行**左滑删除**（同时删本地文件）。
- 底部：`已使用 xxM`，`剩余 xxG 可用`。

## 4. 全屏播放（横屏）

- **顶部左**：`返回 ‹`、剧名 + 第几集、画面模式下拉 `默认 ▾`（默认/拉伸/平铺，点了立刻生效）。
- **顶部右**：`投屏`、`分享`、`更多 ···`。
- **左侧中部**：锁屏 🔒；**右侧中部**：截图 📷。
- **底部**：当前时间/总时长、进度条；下一排 播放/暂停、`下一集 ⏭`；
  右侧 `字幕`、`倍速`、`画质(720P)`、`选集`。
- 控制栏与画面模式下拉在**点屏幕或暂停时出现**，播放几秒后自动隐藏。
- **画面模式实现要求**：对当下可见的 `<video>` 按 `videoWidth/videoHeight` 与容器尺寸
  计算像素宽高并写入（默认=等比装进屏幕、拉伸=铺满变形、平铺=等比放大裁边），
  旋转/进出全屏/换集首帧后重算。**不许只改 CSS 而不改几何**。

## 5. 播放设置面板（全屏点 `···` 从右侧滑出）

- 第一排图标：`下载`、`撑满全屏`、`画中画`、`音频播放`。
- 列表：`定时关闭 ›`；`循环播放`（单集/列表/关闭）；`跳过片头片尾`（开关）；
  `分集标题`（开关）。
- 右上 `✕` 关闭。

## 已并入的旧条目（0.1.16，仍有效）

- 画面填充三档只在全屏出现、记住上次选择；实现按上面的像素几何要求。
- 选集旁的 `下载` 入口点开是集数网格，点一格立刻入共享队列，提示「已加入下载」；
  不再有全选 / 一键全集 / 下载已选，也不在设置里放整部剧队列。
- 已下载列表一行一集，左滑露出红色「删除」，删除时删记录 + 删本地文件（限 App Documents）。
